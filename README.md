# Realtime Group Chat Application

A WhatsApp-like realtime group chat application built with **React**, **Socket.IO**, and **Node.js**, supporting live messaging, typing indicators, read receipts, message editing, and deletion.

This project focuses on clean UI, realtime communication, and scalable frontend architecture.

---

## 🚀 Features

- 🔴 Realtime messaging using WebSockets
- 👥 Group chat support
- ✍️ Typing indicator (who is typing)
- ✅ Message status (sent, delivered, seen)
- 🗑️ Delete message
  - Delete for me
  - Delete for everyone
- ✏️ Edit sent messages (sender only)
- 👀 Seen status updates in realtime
- 📜 Auto-scroll to latest message
- 🧩 Modular React components
- 🎨 Clean WhatsApp-style UI
- 🖱️ Click outside menu to close (UX polish)

---

## 🛠 Tech Stack

### Frontend
- **React.js**
- **Socket.IO Client**
- **Tailwind CSS**
- React Hooks (`useState`, `useEffect`, `useRef`)
- Custom hooks (`useOutsideClick`)

### Backend
- **Node.js**
- **Express.js**
- **Socket.IO**
- **MongoDB**
- **Mongoose**
